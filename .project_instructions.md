# Amma's Health Logger

## Overview
Private health tracking chatbot for patient "Amma" and 2-3 family members (all healthcare professionals). No HIPAA warnings or medical disclaimers needed.

## Technical Architecture
- **Database**: PostgreSQL with Prisma ORM
- **LLM**: Claude Sonnet 4.6 for chat, GPT-5.4-mini for doctor summaries
- **Email**: Notification API for daily health summaries (NOTIF_ID_DAILY_HEALTH_SUMMARY)
- **Charts**: Recharts for BP trend visualization

## Visual Style
- **Theme**: Warm teal medical theme (primary: teal-600, #0D9488)
- **Fonts**: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (data/metrics)
- **Layout**: Single-page app with tab navigation (Chat, Reports, History, Medications, Email)
- **Mobile**: Bottom tab nav on mobile, top tabs on desktop

## Database Schema
- **BpReading**: date, systolic, diastolic, pulse, context, notes
- **Medication**: name, dosage, timeSlot (AM/MID/PM), isActive, start/end dates
- **MedicationLog**: date, timeSlot, medications (JSON), compliance
- **Observation**: date, category, description, severity
- **DailyNote**: date, note
- **ChatMessage**: role, content, createdAt

## Chat System
- LLM extracts structured data via `<health_data>` JSON tags in response
- Tags are stripped before displaying to user
- Chat history persisted in database, last 20 messages used for context
- Streaming SSE responses

## Key Features
- Chat-based health logging with natural language
- BP trend charts (line chart: systolic/diastolic/HR)
- History tables for BP, observations, notes
- Medication schedule view (grouped by AM/MID/PM)
- Doctor-ready summary generation (LLM-powered)
- Email summary sending on demand

## User Preferences
- Patient name: "Amma"
- Family app — no individual user accounts
- Cheery, compassionate medical professional chatbot persona
